# WPFTP PRO - 升级版WPFTP自定义FTP存储插件

WordPress FTP 升级版（简称：WPFTP PRO），在原有 WPFTP 插件基础上进行优化与升级。支持在线编辑、禁止缩略图、图片重命名等功能，并重构代码以提高上传效率。

## 插件简介

WPFTP PRO 可将 WordPress 媒体库文件自动上传至 FTP 空间存储，支持虚拟主机 FTP 与云服务器自建 FTP，实现网站静态资源与网站程序分离，减轻服务器负载，提升访问速度。

## 插件特点

| 功能 | 说明 |
|------|------|
| 在线编辑支持 | 支持已上传图片的在线编辑，编辑后自动同步至 FTP |
| 同步删除 | 媒体库删除文件时，同步删除 FTP 空间中的对应文件 |
| 自定义目录 | 支持自定义二级目录，可指定任意 FTP 存储子目录 |
| 一键替换 | 一键替换数据库中原有静态资源链接为 FTP 空间地址 |
| 禁止缩略图 | 支持一键禁止缩略图生成，仅上传主图 |
| 自动重命名 | 上传文件自动重命名，解决中文文件名或重复文件名问题 |
| 代码优化 | 重构代码，提高上传效率与稳定性 |
| 虚拟主机 | 支持虚拟主机 FTP 空间 |
| 云服务器 | 支持云服务器自建 FTP 空间（可选被动模式） |

## 系统要求

- **WordPress**：4.5.0 及以上
- **PHP**：5.6 及以上
- **测试环境**：WordPress 6.8.1

## 安装方法

1. 将插件文件夹上传至 `/wp-content/plugins/` 目录
2. 在 WordPress 后台「插件」列表中激活插件
3. 在「设置」→「WPFTP PRO设置」中配置 FTP 账户信息

## 配置说明

### 基础设置

| 配置项 | 说明 |
|--------|------|
| FTP服务器IP地址 | 虚拟主机或云服务器 IP，如 `123.123.123.123` |
| FTP端口 | 默认 21，可按需修改 |
| FTP空间绑定域名 | 用于访问 FTP 上文件的域名，如 `http://ftp.example.com` |
| FTP用户名 / 密码 | FTP 登录凭证 |
| FTP被动模式 | 云服务器或特殊网络环境建议开启 |
| FTP存储子目录 | 相对 FTP 根目录的子目录，如 `/wwwroot/` |

### 高级选项

| 选项 | 说明 |
|------|------|
| 自动重命名 | 上传时自动生成唯一文件名，避免中文或重复文件名问题 |
| 不在本地保存 | 仅上传至 FTP，不在服务器本地保留备份 |
| 禁止缩略图 | 仅生成并上传主图，不生成缩略图 |

## 支持的文件类型

- **图片**：jpg, jpeg, png, gif, webp
- **文档**：pdf, doc, docx, xls, xlsx
- **压缩**：zip, rar, tar, gz
- **视频**：mp4, webm, ogg
- **音频**：mp3, wav

单文件最大支持 50MB。

## 技术架构

插件采用模块化设计，主要包含以下类：

- **WPFTPConfig**：集中管理配置
- **WPFTPLogger**：日志记录，支持数据库存储与错误日志
- **WPFTPConnection**：FTP 连接管理，支持连接池与重试机制
- **WPFTPOperations**：文件上传、删除等操作，含文件类型与大小校验

## 常见问题

1. **插件出错时**：开启 WordPress 调试模式，查看 `error_log` 获取详细错误信息
2. **本地备份**：可选择在对象存储与本地同时保留文件（不勾选「不在本地保存」）
3. **已有网站迁移**：调试无误后，需将原有本地静态资源上传至 FTP，并使用「一键替换」功能更新数据库中的链接路径
